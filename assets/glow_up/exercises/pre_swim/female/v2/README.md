# Glow Up Pre-Swim — Seven Individual Exercise Sequences

This package contains the seven approved women-only Pre-Swim exercise sequences split into individual files for Claude Code.

## Contents

- 7 exercise folders
- 6 individual frames per exercise
- 42 base individual frame images
- 12 additional opposite-side frames for Calf Stretch and Figure-Four Stretch
- 54 deployable frame images total
- Native undistorted crops
- Standardized `400 × 600` app frames
- One manifest per sequence
- One routine-level sequence index
- Original approved source strip retained inside each exercise folder for QA

## Correct project location

Extract to:

`C:\Projects\glow_up\assets\glow_up\exercise_animations\pre_swim\female\v1`

Claude Code should use `app_frames_400x600` for the app and keep `native_frames` plus `source_sequence.png` as QA references.

## Locked rules

- These assets are female-only.
- Do not add or recover male assets or male fallbacks.
- Do not treat a six-frame strip as one static exercise image.
- Load and play frames 01 through 06 in manifest order.
- For `BOTH_SIDES`, do not complete after only one side.
- Calf Stretch and Figure-Four Stretch include dedicated opposite-side folders because their approved source strips showed only one side.
- For `ALTERNATING`, complete the full alternating sequence.
- Never synthesize missing poses or create impossible in-between movements.
